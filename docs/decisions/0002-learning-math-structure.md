# 0002. 構成を learning-math に合わせ、数学はそちらへリンクする

- ステータス: **採用**（2026-09-30）
- 対象: リポジトリ全体の構成（0001 の「lessons/ 1 ページ 1 レベル」を置き換える）

## 背景

作者の公開教材 learning-math（大人向けの数学・日本語）は、章フォルダ・1 ページ 1 トピック・
notebooks/columns の併置・ページ末のナビゲーション表・ワンクリック起動・リンク検査の CI という
構成で運用されている。この教材も同じ作者の教材群として揃えたい。また、CSI の学習には
波・対数・標準偏差・ベクトルなどの数学が出てくるが、子ども向けの本文で深入りはできない。

## 決定

- ルート直下に `start_here/` と `01_waves/`〜`06_free_research/`、`appendix/`、`glossary/` を置く。
  各章は README（章 TOP）＋番号付きページ＋`notebooks/`＋`columns/`
- ページの型（冒頭の「コードを動かすには」、末尾のナビゲーション表）は
  `docs/maintainers/page_template.md` に定め、ナビゲーション表の有無をテストで強制する
- 起動は `start.sh` / `start.bat` / `start.ps1` / `lab.py`（learning-math から移植）。
  依存は 1 回の `uv sync` ですべて入る（extras をやめた。子どもが覚える手順を減らすため）
- リンク検査は learning-math の `scripts/check_links.py` を移植して CI で実行する
- 数学は本文で説明しきらず、learning-math の該当ページへ絶対 URL でリンクする。
  対応表は `appendix/math_map.md` に一元化し、各ページの「📐」欄はそこから写す
- 英語が基本・日本語併記（0001）とライセンス CC BY 4.0（0001）は維持する
  （learning-math は日本語のみ・文書 CC BY-NC-SA だが、対象と目的が違うため揃えない）

## 根拠

- 同じ作者の教材で構成が揃っていれば、学習者も保守者も迷わない
- learning-math は大人向けで日本語のみのため、リンク欄に必ずその旨を書き、
  「おうちの人といっしょに／中学生以上」と案内する
- アンカー（見出し）へのリンクは相手側の見出し変更で壊れるので、ファイル単位でリンクする
