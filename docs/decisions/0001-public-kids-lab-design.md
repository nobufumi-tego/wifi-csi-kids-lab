# 0001. 小中学生が生成AIと学ぶ公開教材として、研究用リポから独立に新設する

- ステータス: **採用**（2026-09-30）
- 対象: リポジトリ全体

## 背景

以前の個人用の学習リポ（private）は研究者向けの内容で、そのまま公開するには
履歴の書き換え（force push）が必要だった。

GitHub の調査（2026-09-30）では、CSI 関連リポは約 1,000〜1,300 件あるが、
体系的に学ぶ教材型はほぼ無く、日本語では体系的なものが見当たらなかった。

## 決定

- 新しい公開リポを**白紙の履歴**で作る。旧リポは private のまま研究用に使い続け、相互に参照しない
- 対象は日本の小学生〜中学生。生成AIを家庭教師役にする前提で `AGENTS.md` を AI への指示書にする
- **英語を基本、日本語を併記**。各文書は `X.md` と `X.ja.md` の対。テストで対の欠けを検出する
- サンプルデータは**合成のみ**（`csi_lab.simulate`）。実在の家・人の記録は含めない。`data/` は git 管理外
- 受信機は振幅を CSV の 1 行で出す（Excel/pandas でそのまま開ける）。合成データも同じ形式にし、
  すべてのレッスンが実機と合成の両方で動くようにする
- ライセンス: コード MIT、文書 CC BY 4.0
- コミットの作者は GitHub の noreply アドレス

## 根拠

- 履歴を持ち込まなければ、公開に向かない過去の記述を消すための force push が要らない
- 抜粋を旧リポと並行保守すると同期が崩れ、写し間違いの事故が起きやすい。そのため「移行」ではなく
  「独立した新設」とし、旧リポとは内容を同期しない
- 合成データは公開しても誰の記録でもない。現実より簡単になる点は教材中で明示する
  （シミュレーターは歩行/静止の差が約 3 倍で、実際の部屋より分かりやすい）
- 研究者向けの処理（HMM・チャンネル掃引・位相校正・記録メタデータ）は持ち込まない。
  子どもが最初の自由研究で必要とする範囲（可視化・窓の標準偏差・しきい値・決定木）に絞る
