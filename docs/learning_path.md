# Learning path — every page in order

Go from top to bottom. Each chapter builds on the one before. You can stop after any
chapter and still do a small project with what you learned. Chapters 1, 2, 4 and 5 need
only a computer (without the Chapter 3 hardware you can use the pretend data).
Before Chapter 3, read the [safety page](../start_here/04_safety.md) together with an adult.

- **💡 Run the code on this page** tells you which notebook to open.
- **🤖 Ask your AI** has example questions for your AI study buddy. Ask in your own words too, and always ask *why*.
- **Check yourself**: think before you open the answers.
- **📐 Math behind this page** links to learning-math, a math course for adults.
