# 保護者の方・先生方へ

## お子さんが取り組むこと

このラボでは「Wi-Fi センシング」を学びます。人が動いたときに Wi-Fi の電波がどう変わるかを
測る技術です。短い「はじめに」の章のあと、5 つの章と自由研究の章に進みます
（全ページの一覧は[学習の道すじ](learning_path.ja.md)にあります）。

| 章 | 内容 | 目安の時間（おおよそ） |
|---|---|---|
| [0 はじめに](../start_here/README.ja.md) | Wi-Fi センシングとは、ラボの開き方、AI との学び方、安全 | 1〜2 時間 |
| [1 電波と波](../01_waves/README.ja.md) | 電波・反射・干渉の考え方 | 1〜2 時間 |
| [2 CSI の基本](../02_csi_basics/README.ja.md) | 練習用（シミュレーション）の CSI データを Python で図にする | 1〜3 時間 |
| [3 作ってみる](../03_build/README.ja.md) | ESP32 ボード 2 台にプログラムを書き込み、実際のデータを記録する | 2〜4 時間（大人と一緒に） |
| [4 動きを見つける](../04_analysis/README.ja.md) | 「動きの数値」を計算し、しきい値を決める | 2〜3 時間 |
| [5 機械学習](../05_machine_learning/README.ja.md) | 簡単な分類器を学習させ、テストする | 2〜4 時間 |
| [6 自由研究](../06_free_research/README.ja.md) | 計画・測定・まとめ | 数回分 |

時間は作者によるおおよその見込みで、年齢や経験によって大きく変わります。
第 3 章以外は、パソコンだけで取り組めます。

## 必要なもの・費用

- ソフトウェアをインストールできるパソコン（Windows、macOS、Linux、または Linux を有効にした ChromeOS）
- 第 3 章のみ: 無線モジュールに**技適マーク**がある **ESP32 開発ボード 2 台**と、
  **データ通信ができる USB ケーブル 2 本**（充電専用のケーブルもあるのでご注意ください）
- ここで使うソフトウェアはすべて無料です

## 大人が手伝ってほしいところ

- **ソフトウェアのインストール**（起動スクリプトが uv と Python の道具を入れます。第 3 章では Arduino IDE と、場合によって USB ドライバも必要です）と、権限の許可
- **部品の購入**。技適マークを確認してください。[安全のページ](../start_here/04_safety.ja.md)をご覧ください
- **電気**。電源は USB のみです。使い終わったらボードを抜いてください
- **プライバシー**。部屋にいる全員が記録に同意していることを確かめ、記録はご家庭の
  パソコンの中に置いてください。Wi-Fi センシングでは人の行動が分かってしまうことがあるため、
  同意が大切です
- **AI ツール**。AI サービスにはそれぞれ利用規約があり、**利用できる年齢の条件**も定められています。
  使う予定のサービスの規約をご確認ください。必要に応じて保護者の方がアカウントを用意し、
  お子さんと一緒にお使いください

## AI と一緒に学ぶことについて

[`AGENTS.md`](../AGENTS.md) というファイルで、AI のコーディングツールに先生役をお願いしています。
具体的には、答えの前にヒントを出すこと、安全とプライバシーのルールを守ること、
お子さんのレポートを代わりに書かないことです。
それでも AI は間違えることがあります。コードを実際に動かしたり、レッスンと見比べたりして
確かめるよう、声をかけてあげてください。詳しくは [AI との学び方](../start_here/03_learning_with_ai.ja.md) をご覧ください。

## 自由研究として取り組む場合

- 完成度の高い結果よりも、**お子さん自身の問い・予想・考えた道すじ**を大切にしてください。
  「うまくいかなかった。理由はこう考えた」も立派な成果です。
- **AI 利用メモ**（何を聞いたか・何が分かったか・自分で何を確かめたか）を残すよう
  すすめてください。AI の使い方が見えるようになり、話し合いもしやすくなります。
- 練習用（シミュレーション）のデータは練習に役立ちます。ただし結果をまとめるときは、
  シミュレーションなのか実測なのかをはっきり書くようにしてください。
- AI の使い方についてのきまりは学校ごとに違います。迷ったら学校にご確認ください。

テーマ例と研究シートは[第 6 章](../06_free_research/README.ja.md)にあります。
あわせて[おことわり](../DISCLAIMER.ja.md)もご覧ください。この教材は生成 AI を使って作成しており、
専門家の確認は受けていません。
