# 3-3. 記録する — はじめての本物の CSI

部屋を準備して、「だれも動いていない」と「歩いている」を記録し、絵にします。

> 💡 **このページのコマンドは**、このラボのフォルダで開いたターミナルで実行します。
> ターミナルがはじめての人 → [0-2. ターミナルと uv](../start_here/02_terminal_and_uv.ja.md)

## 1. 部屋の準備

- S と R を **3 m くらい** はなして、**同じ高さ** に置きます（たとえば、いす 2 つや、たなの上）。
  2 台を結ぶまっすぐの線の上には、何も置かないようにします
- くらべたい記録は、ぜんぶ **同じ置き方** で記録します
- 部屋にいる人みんなに、何をするのかを伝えて、**先に「いいよ」をもらいましょう**。
  Wi-Fi センシングは人が何をしているかがわかってしまうので、その人の「いいよ」が必要です
  （[0-4. 安全のために](../start_here/04_safety.ja.md) を見てね）

R をパソコンにつなぎます。S の電気は、パソコンからでもモバイルバッテリーからでもかまいません。

## 2. ポートを見つける

```bash
uv run csi-lab ports
```

ボードを 1 台だけつないでいれば、`capture` が自動で見つけてくれます。何台もあるときは、
`--port <名前>` をつけます（たとえば `--port COM3` や `--port /dev/ttyUSB0`）。

## 3. まず、だれもいない部屋を記録する

部屋から出るか、S と R を結ぶ線から遠いところでじっと座ってから、次のコマンドを実行します。

```bash
uv run csi-lab capture --label empty --seconds 30
```

ファイルは `data/my-recordings/` に、日づけ・時刻・ラベルのついた名前で保存されます
（[`data/README.ja.md`](../data/README.ja.md) を見てね）。Ctrl+C でとちゅうで止めても、
それまでの記録は残ります。

いつも最初に「empty」を記録しましょう。これが **基準**、つまり、ほかのすべてとくらべるための
ものさしになります。

## 4. 動いているところを記録する

```bash
uv run csi-lab capture --label walk --seconds 30
```

記録している間、S と R を結ぶ線を横切るように、ゆっくり行ったり来たりしましょう。

## 5. 絵にする

```bash
uv run csi-lab show data/my-recordings/<あなたのファイル>.csv
```

ファイルのとなりに `<あなたのファイル>.png` という絵が保存されます。[第 2 章](../02_csi_basics/README.ja.md)
の練習用の記録とくらべてみましょう。にているところは？ ちがうところは？
本物のデータは、ふつう、もっとざわざわしています。それでふつうです。

## 6. 実験のよい習慣

- **一度に変えるのは 1 つだけ。** 距離と、動く人を同時に変えると、どちらのせいで変わったのか
  わからなくなります
- **くり返す。** 同じ条件で、少なくとも 3 回ずつ記録しましょう
- **実験ノートをつける。** 記録ごとに、次のことを書きます

| 書くこと | 例 |
|---|---|
| 日づけと時刻 | 2026-08-01 14:05 |
| 場所（住所は書かない） | リビング |
| S と R の距離と高さ | 3 m、どちらも 70 cm |
| 部屋にいた人と、「いいよ」をもらったこと | わたし（OK）、弟（OK） |
| 何をしたか | 線を 5 回横切った |
| いつもとちがうこと | 20 秒くらいでドアが開いた |

> 🤖 **AI に聞いてみよう**
> - 「ドアを閉めると CSI が変わるか調べたいです。公平な実験の計画をいっしょに考えて。
>   何を同じにして、何を変えればいい？」
> - 「これがわたしの実験ノートです: … 書きわすれている大事なことはある？」

## たしかめよう

1. 最初に「empty」を記録するのはなぜですか？
2. ボードを近づけて、**さらに** 窓も開けたら、CSI が変わりました。この実験の何がいけないのでしょう？
3. 記録の前に、部屋にいる人に聞くのはなぜですか？

<details><summary>こたえ</summary>

1. 基準になるから。「何も動いていない」とき、**この部屋** ではどう見えるのかがわかって
   いないと、「何かが変わった」とは言えない
2. 2 つのことを同時に変えたので、どちらのせいで変わったのかわからない
3. Wi-Fi センシングは、人が何をしているかがわかってしまうから。聞かずに記録するのは、
   その人に対してフェアではない

</details>
