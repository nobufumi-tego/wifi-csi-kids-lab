# 0-4. 安全のために — 電気・電波のきまり・プライバシー

**[第 3 章](../03_build/README.ja.md)（作って記録する）の前に**、おうちの人といっしょに読みましょう。

## 1. 電気

- ボードの電源は **USB だけ**にします。パソコンか、USB の電源アダプターから取ります。
- コンセント、むき出しの電池、ほかの電源にはつながないでください。電源アダプターを開けてもいけません。
- 電気が流れているときは、**金属のピンにさわらない**ようにします。ボードは、かわいた、
  金属でない場所に置きます。硬貨やアルミホイル、工具の上に置くと、ピンどうしがつながってしまいます。
- ボードは**温かく**なることがあります。熱くなったり、へんなにおいがしたりしたら、
  すぐに USB を抜いて、大人に知らせましょう。
- 終わったら **USB を抜きます**。

## 2. 日本の電波のきまり（技適・電波法）

日本では、電波を出す機械は、国のきまりに合っていると認められたものしか使えません。
認められた機械には **技適マーク**（〒 を丸でかこんだような印と番号）がついています。

- 使うのは、**無線モジュールに技適マークがある** ESP32 ボードだけです。買う前と、
  とどいたボードの両方で確かめましょう。
- 外国のお店から買ったボードには、マークが**ない**ことがよくあります。このラボでは使わないでください。
- **改造しないでください。** アンテナをつけ足したり、切ったり、はんだづけしたりしてはいけません。
  電波を強くする設定もしてはいけません。このリポジトリのプログラムを、そのまま使います。
- わからないときは、手を止めて、おうちの人に聞きましょう。

## 3. プライバシーと「いいよ」をもらうこと

Wi-Fi センシングでは、カメラがなくても**人がいるか、何をしているか**がわかってしまうことがあります。
だから、気をつけて使う必要があります。

- 記録する前に、**部屋にいる全員に聞きます**。「いいよ」と言った人だけを記録します。
  何を測るのかも伝えましょう。
- となりの家や、ほかの人の家、知らない人がいる場所に向けて測っては**いけません**。
  かべの向こうの、ほかの人の場所を「のぞこう」としてもいけません。
- **記録は自分のパソコンの中に置きます。** 記録は `data/` に入ります。このフォルダは
  git が無視するようにしてあります（[`data/README.ja.md`](../data/README.ja.md)）。インターネットに上げたり、人に送ったりしないでください。
- ファイル名やメモに、本当の名前・住所・学校名を書かないでください。
  `person-A` や `room-1` のような名前を使いましょう。

## 4. 結果を発表するとき

- 見せるのは**グラフや数字**です。人を記録した生のデータは見せません。
- 名前、顔、住所、住んでいる場所がわかる写真は出しません。
- データが**シミュレーション（練習用のにせもの）**なのか、**本物**なのかをはっきり書きます。

「あぶないかも」「よくないかも」と感じたら、手を止めて大人に聞きましょう。それがいつでも正しい答えです。

プライバシーについてもっと考えたい人は、コラム
[人に気づく Wi-Fi](columns/01_sensing_and_privacy.ja.md) を読んでみてください。
