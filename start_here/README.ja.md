# 第 0 章: はじめに

Wi-Fi CSI キッズラボへようこそ！ このラボでは、人が動くと Wi-Fi の電波がどう変わるかを
調べます。Python で波を絵にしたり、やってみたい人は ESP32 というボード 2 台で小さな
センサーを作ったりします。そして最後に、自分の自由研究にまとめます。

この章は、そのための準備です。Wi-Fi センシングとは何か、ラボの開き方、AI といっしょに
学ぶ方法、そして安全のための約束を読みます。
