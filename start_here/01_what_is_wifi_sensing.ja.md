# 0-1. Wi-Fi センシングってなに？ — きみが動いたことに気づく Wi-Fi

Wi-Fi は、動画やメッセージを送るためのものです。でも同じ電波を使って、部屋の中で
だれかが動いたことに気づくこともできます。このページでは、その考え方をお話で説明します。
コードは出てきません。

## はね返る波でいっぱいの部屋

真っ暗な部屋の、一方のはしに懐中電灯、反対のはしに光を測る機械があると想像してください。
機械にとどくのは、懐中電灯から**まっすぐ**来る光だけではありません。かべ、机、たな、
そしてきみの体に**はね返って**来る光もとどきます。

Wi-Fi の電波も、これと似ています。目には見えませんが、かべや家具や人にはね返ります。
だから受信機には、同じ波の**コピーがたくさん**、それぞれちがう道を通ってとどきます。

```text
   S（送信機） ─────────────────────► R（受信機）     まっすぐの道
        \                           ↗
         \──► かべ ──►   人   ──/                     はね返る道
```

## 動くと、まざり方が変わる

受信機では、たくさんのコピーが足し合わされます。助け合って大きくなることもあれば、
打ち消し合って小さくなることもあります。人が歩くと、人ではね返る道が長くなったり
短くなったりするので、まざり方がどんどん変わります。

Wi-Fi のチップは、このまざり方をくわしく教えてくれます。それを **CSI**
（チャネル状態情報）といいます。[第 2 章](../02_csi_basics/README.ja.md)で出会います。

## Wi-Fi センシングにできること・できないこと

このラボの道具（小さな ESP32 ボード 2 台とパソコン）で、次のことを調べられます。

- 部屋は**空っぽ**？ それとも、だれかいる？
- だれかが**動いている**？ それとも**じっとしている**？
- **呼吸**のような、ゆっくりした決まった動きは見える？（練習用のデータでは見えます。
  本物の部屋では、ずっとむずかしいです）

**期待してはいけない**こともあります。

- カメラのような写真は作れません。
- それが**だれか**はわかりません。
- まちがえやすいです。ドア、せんぷう機、ペット、ほかの人でも波は変わります。
- 病院で使う機械や、防犯のための機械では**ありません**。

## 気をつけて使うわけ

カメラがなくても、Wi-Fi センシングでは、だれかが家にいるか、だいたい何をしているかが
わかってしまいます。これは人に知られたくない情報（プライバシー）です。
だから、このラボではいつも次のことを守ります。

- 記録する前に、部屋にいる全員に「いいよ」をもらう
- 記録は自分のパソコンの中に置く
- ほかの人の家は、ぜったいに測らない

くわしくは[安全のページ](04_safety.ja.md)にあります。コラム
[人に気づく Wi-Fi](columns/01_sensing_and_privacy.ja.md) でも、もう少し話します。

## たしかめよう

1. 受信機に、同じ波のコピーがたくさんとどくのはなぜ？
2. 人が歩くと、波のまざり方が変わるのはなぜ？
3. このラボの Wi-Fi センシングにできないことを 1 つ言ってみよう。

<details><summary>こたえ</summary>

1. 波がかべや家具や人にはね返って、いろいろな道を通って受信機にとどくからです。
2. 人ではね返る道が長くなったり短くなったりして、コピーの足し合わさり方が変わるからです。
3. たとえば、写真は作れない、だれかはわからない、病院で使う機械ではない、など。

</details>
