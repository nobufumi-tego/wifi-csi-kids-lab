# Chapter 0: Start here

Welcome to the Wi-Fi CSI Kids Lab! In this lab you find out how Wi-Fi radio waves
change when people move. You will draw the waves with Python, build a small sensor
from two ESP32 boards if you want to, and finish with your own free-research project.

This chapter gets you ready: what Wi-Fi sensing is, how to open the lab, how to learn
with an AI study buddy, and how to stay safe.

> ⚠️ This lab was made by one person together with generative AI and has not been
> checked by experts. It may contain mistakes. See the [disclaimer](../DISCLAIMER.md).
