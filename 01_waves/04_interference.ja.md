# 1-4. 波の足し算（干渉） — 人が動くと Wi-Fi が変わるわけ

いろいろな道を通ってきた波は、受信機で出会うと足し算されます。強め合うこともあれば、
弱め合うこともあります。このページでは、そのしくみと、それを使うと Wi-Fi が人の動きに
気づけるわけを見ていきます。このラボ全体の、いちばん大事なアイデアです。

> 💡 **このページのコードを動かすには**: ラボを起動して（`./start.sh` か `start.bat` を
> ダブルクリック、または `uv run lab.py`）、[`notebooks/01_waves.ipynb`](notebooks/01_waves.ipynb) を開きます。
> ターミナルがはじめての人 → [ターミナルと uv](../start_here/02_terminal_and_uv.ja.md)

## 池に小石を 2 つ

池に小石を **2 つ** 同時に落としてみましょう。山と山が出会うところでは、水がいつもより
高く上がります。波が **強め合う** のです。山と谷が出会うところでは、水は平らなままです。
波が **弱め合う** のです。これを **干渉（かんしょう）** といいます。

```text
 強め合う:  /\  +  /\   =   /\        弱め合う:  /\  +       =   ____
           /  \   /  \     /  \                 /  \   \  /
                          /    \                        \/
```

## 強め合うか弱め合うかを決めるもの

受信機では、まっすぐ来た波と、はね返って来た波が出会います。強め合うか弱め合うかは、
はね返る道が **どれだけ長いか** を、波長 $\lambda$（約 12.5 cm）とくらべて決まります。

| はね返る道が長い分 | 出会うのは… | 結果 |
|---|---|---|
| $0,\ \lambda,\ 2\lambda,\ \dots$（波長のちょうど整数倍） | 山と山 | 強め合う |
| $\tfrac{1}{2}\lambda,\ 1\tfrac{1}{2}\lambda,\ \dots$ | 山と谷 | 弱め合う |
| そのあいだ | 少しずつ | そのあいだ |

受信機が受け取るのは、すべての道の波の **合計** です。数学では「ぜんぶ足す」を
$\Sigma$（シグマ）という記号で書きます。

$$
\text{受け取る波} = \sum_{\text{道}} \text{その道を通った波}
$$

## ためそう: Python で 2 つの波を足す

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 3, 600)                    # 場所（波長いくつ分か）
shift = 0.5                                   # はね返る道が長い分（波長いくつ分か）
wave_a = np.sin(2 * np.pi * x)                # まっすぐな道
wave_b = np.sin(2 * np.pi * (x - shift))      # はね返る道

plt.plot(x, wave_a, label="path A")
plt.plot(x, wave_b, label="path B")
plt.plot(x, wave_a + wave_b, label="A + B", linewidth=3)
plt.legend()
plt.xlabel("position (wavelengths)")
plt.show()
```

`shift` を `0`、`0.25`、`0.5`、`1.0` に変えてみましょう。太い線（A + B）がいちばん大きく
なるのはいつ？ ほとんど消えてしまうのはいつ？

## 人が動くと、強め合う・弱め合うが入れかわる

[1-3](03_reflection_and_paths.ja.md) の、$(1.5, y)$ に立つ人を思い出しましょう。
弱め合いが強め合いに変わるには、はね返る道が **波長の半分**、約 6 cm
（チャンネル 11 で 0.0609 m）変わるだけでいいのです。道の長さの式を使って、人がどれだけ
動けばそうなるかを計算しました。

| 人のはじめの場所 | 線からはなれる向きに動く長さ | 道の長さの変化 |
|---|---|---|
| $y = 1.0$ m | 5.4 cm | 波長の半分 |
| $y = 0.5$ m | 8.9 cm | 波長の半分 |

たった数 cm です！ だから人が歩いているあいだ、受信機の電波は **上がったり下がったり**
をくり返します。だれも動かなければ、道はどれも変わらないので、電波はほとんど一定です。

> **これが Wi-Fi センシングのアイデアのすべてです:** 電波のゆれを見れば、カメラが
> なくても、なにかが動いたことがわかるのです。

## 「車線」ごとに結果がちがう

Wi-Fi は波を 1 つだけ送っているのではありません。周波数が少しずつちがう波を、
たくさんならべて送っています。だから波長も少しずつちがいます（この「車線」には
[第 2 章](../02_csi_basics/README.ja.md) で出会います）。同じ部屋でも、ある車線では
強め合い、別の車線では弱め合うことがあるのです。

例を計算しました。大きさ 1 のまっすぐな波と、大きさ 0.5 のはね返った波を、
チャンネル 11 の 3 つの車線（番号 −28、0、+28）で足したときの大きさです。

| 人のいる場所 | 車線 −28 | 車線 0 | 車線 +28 |
|---|---|---|---|
| $y = 1.0$ m | 1.49 | 1.50 | 1.50 |
| $y = 2.0$ m | 0.76 | 0.60 | 0.51 |

（1.5 ＝ しっかり強め合う、0.5 ＝ しっかり弱め合う。）$y = 2$ m では車線ごとに結果が
ちがいます。長い分の 2 m が、ある車線では波長 16.37 こ分、別の車線では 16.48 こ分に
なるからです。**全部の車線** を測ると、数 1 つよりずっと多くのことがわかります。

## たしかめよう

1. 2 つの道の長さが波長の半分だけちがいます。強め合う？ 弱め合う？
2. 弱め合いから強め合いに変わるには、はね返る道がだいたいどれだけ変わればいい？
3. 人が部屋を歩くと、電波がゆれるのはなぜ？

<details><summary>こたえ</summary>

1. 弱め合う。一方の山と、もう一方の谷が出会うから。
2. 波長の半分くらい。約 6 cm。
3. 人に当たってはね返る道の長さが変わりつづけるので、ほかの道と強め合ったり
   弱め合ったりが入れかわりつづけるから。

</details>
