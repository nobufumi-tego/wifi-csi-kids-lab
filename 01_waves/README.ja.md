# 第 1 章: 電波と波 — 電波はどうやって進むの？

**この章のゴール:** 電波とはどんなものかを知り、同じ Wi-Fi の電波でも、場所によって
強く届いたり弱く届いたりするのはなぜかを理解します。最後には、Wi-Fi センシングの
いちばん大事なアイデアがわかります。

**時間:** 約 1 時間（短いページ 4 つ ＋ ノートブック（やりたい人だけ））

**必要なもの:** 知りたい気持ちだけ。Python の部分はやらなくても大丈夫です。
ためすときは、まずラボを起動してください（`./start.sh`、`start.bat` をダブルクリック、
または `uv run lab.py`。[ホーム](../README.ja.md) を見てください）。
