# 1-2. 波長と周波数 — Wi-Fi の波 1 つの長さは？

どんな波も、2 つの数であらわせます。このページでは、その 2 つをかんたんなルールで
つなぎます。そして、Wi-Fi の波 1 つの長さが、ちょうど手のひらくらいだとわかります。

> 💡 **このページのコードを動かすには**: ラボを起動して（`./start.sh` か `start.bat` を
> ダブルクリック、または `uv run lab.py`）、[`notebooks/01_waves.ipynb`](notebooks/01_waves.ipynb) を開きます。
> ターミナルがはじめての人 → [ターミナルと uv](../start_here/02_terminal_and_uv.ja.md)

## 2 つの数

- **周波数（しゅうはすう）** $f$: 波が **1 秒間に** 何回上下するか。単位はヘルツ（Hz）。
  Wi-Fi でよく使う **2.4 GHz（ギガヘルツ）** は、1 秒間に約 24 億回です。
- **波長（はちょう）** $\lambda$（ギリシャ文字の「ラムダ」）: 波の山から、となりの山までの長さ。

```text
   山          山          山
   /\         /\         /\
  /  \       /  \       /  \
 /    \     /    \     /    \
       \   /      \   /
        \_/        \_/
   |<-------->|
    波長 λ
```

## 2 つをつなぐルール

波は 1 回上下するたびに、波長 1 つ分だけ前に進みます。1 秒間に $f$ 回上下するので、
1 秒で $f \times \lambda$ 進みます。これが波の速さ $c$（光の速さ。1 秒に約 3 億 m）と
同じになるはずです。

$$
c = f \times \lambda \qquad\Longrightarrow\qquad \lambda = \frac{c}{f}
$$

2.4 GHz の Wi-Fi なら:

$$
\lambda = \frac{300{,}000{,}000\ \text{m/秒}}{2{,}400{,}000{,}000\ \text{回/秒}} = 0.125\ \text{m} \approx 12.5\ \text{cm}
$$

だいたい手のひらの長さです。**12.5 cm をおぼえておきましょう。** この章のどのページにも
出てきます。

## ためそう: Python で計算する

```python
c = 299_792_458          # 光の速さ（m/秒。正確な値）
f = 2.4e9                # 2.4 GHz = 2.4 × 10^9 Hz
print(c / f, "m")        # 約 0.1249 m
```

| 周波数 | 波長（計算した値） |
|---|---|
| 2.4 GHz | 0.1249 m ≈ 12.5 cm |
| 2.462 GHz（Wi-Fi のチャンネル 11。このラボで使う） | 0.1218 m ≈ 12.2 cm |
| 5.0 GHz | 0.0600 m ≈ 6 cm |

周波数が高いほど、波長は短くなります。周波数が 2 倍になると、波長は半分です。
