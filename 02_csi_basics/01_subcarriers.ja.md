# 2-1. サブキャリア — Wi-Fi は 56 車線の高速道路

第 1 章では「Wi-Fi の波」を 1 本のように話しました。本当は、Wi-Fi は小さな波をたくさん
ならべて送っています。このページでは、その「車線」と出会い、車線がたくさんあると
センシングにとってうれしいわけを知ります。

## 1 つのチャンネルに、たくさんの車線

Wi-Fi は **チャンネル**（はば 20 MHz の周波数のまとまり）を使います。そのまとまりを、
細い **車線** にたくさん分けています。車線がたくさんある高速道路のようなものです。
車線 1 本 1 本に、小さな波が乗っています。この車線を **サブキャリア** といい、
このような送り方を **OFDM** といいます（長い正式名はおぼえなくて大丈夫です）。

```text
周波数 ->
 |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |
-28 ...            -1   (0)  1              ...          28
                         ^ まん中の車線は使わない
```

- となりの車線とは **312.5 kHz** はなれています。
- このラボでは **56 本の車線** を使います。番号は −28〜−1 と 1〜28。まん中の 0 番は使いません。
- チャンネル 11（中心 2.462 GHz）では、−28 番は約 2.4533 GHz、+28 番は約 2.4708 GHz です
  （$2.462\ \text{GHz} \pm 28 \times 312.5\ \text{kHz}$）。

## 車線ごとに、部屋の見え方が少しちがう

車線ごとに周波数が少しずつちがうので、波長も少しずつちがいます
（[1-2](../01_waves/02_wavelength_and_frequency.ja.md) の $\lambda = c/f$）。
[1-4](../01_waves/04_interference.ja.md) で見たように、同じ部屋の同じ道でも、ある車線では
**強め合い**、別の車線では **弱め合う** ことがあります。だから、車線ごとにちがう大きさで
届くのです。

これはセンシングにとってうれしいことです。数 1 つではなく、同じしゅんかんの同じ部屋を
**56 通りの見方** で見られるのですから。

> 🤖 **AI に聞いてみよう**

> - 「車線が 312.5 kHz ずつはなれていたら、56 本合わせたはばは？ わたしが計算するから、あとで答え合わせして」
> - 「まん中の車線（0 番）を使わないのはなぜ？」

## たしかめよう

1. Wi-Fi のチャンネルの中の、小さな波のことをなんと呼ぶ？
2. このラボでは車線を何本使う？ 使わない番号は？
3. 車線ごとにちがう大きさで届くのはなぜ？

<details><summary>こたえ</summary>

1. サブキャリア。
2. 56 本（−28〜−1 と 1〜28）。0 番は使わない。
3. 車線ごとに波長が少しちがうので、部屋の道どうしの強め合い・弱め合いが車線ごとにちがうから。

</details>
