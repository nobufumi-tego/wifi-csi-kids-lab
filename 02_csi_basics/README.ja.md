# 第 2 章: CSI の基本 — データを見てみよう

**この章のゴール:** CSI とは何かを知り、パソコンで「まねっこの記録」を作って、Python で
絵にします。最後には、だれもいない部屋と、人が歩いている部屋のちがいが **目で見て**
わかるようになります。

**時間:** 約 1〜1.5 時間

**必要なもの:** ラボの準備ができたパソコン（`./start.sh`、`start.bat` をダブルクリック、
または `uv sync`。[ホーム](../README.ja.md) を見てください）。ESP32 はまだいりません。
