# Chapter 2: CSI basics — look at the data

**Goal:** know what CSI is, make pretend recordings on your computer, and draw them with
Python. By the end you will *see* the difference between an empty room and a room where
someone walks.

**Time:** about 1–1.5 hours

**What you need:** a computer with the lab set up (`./start.sh`, double-click
`start.bat`, or `uv sync`; see the [home page](../README.md)). No ESP32 yet.
