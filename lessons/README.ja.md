# レッスン一覧

順番に進めてください。レベルごとに、前のレベルの内容を使います。どのレベルで止めても、
そこまでに学んだことで小さな自由研究ができます。

| レベル | レッスン | すること | 目安 |
|---|---|---|---|
| 1 | [電波ってなに？](1-waves/README.ja.md) | 電波の正体と、はね返った波が強め合ったり弱め合ったりするわけを知る。機材はいりません | 小学5年生〜 |
| 2 | [CSI を見てみよう](2-csi-basics/README.ja.md) | パソコンで「まねっこの記録」を作り、Python で絵にする | 小学5年生〜 |
| 3 | [送信機と受信機をつくろう](3-build/README.ja.md) | ESP32 を 2 台プログラムして、本物の CSI を記録する | おうちの人・先生といっしょに |
| 4 | [動いた？止まってた？](4-analysis/README.ja.md) | CSI から「動きの数」を作り、しきい値を決める | 中学生〜 |
| 5 | [はじめての機械学習](5-machine-learning/README.ja.md) | コンピューターに見分け方を学ばせ、どれくらい正しいかを正直に確かめる | 中学生〜 |

レベル 3 を始める前に、[安全のガイド](../guides/safety.ja.md)をおとなの人といっしょに読んでください。

## レッスンの使い方

- **やってみよう** には、そのまま写して使えるコマンドがあります
- **AI に聞いてみよう** には、AI の学習パートナーへの質問の例があります。自分の言葉でも聞いてみましょう。
  そして、いつも「なぜ？」を聞きましょう
- **たしかめよう** には問題が 3 つあります。答えを開く前に、自分で考えてみてください
