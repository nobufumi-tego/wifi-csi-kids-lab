# `data/` フォルダについて

このフォルダには、**自分のパソコンの中だけ**に置く記録を入れます。この 2 つの README
以外は git が無視するので、インターネットに上がることはありません。

| フォルダ | 入れるもの | 作り方 |
|---|---|---|
| `data/samples/` | 練習用（シミュレーション）の記録: `empty`・`still`・`walk`・`breathe`・`wave`・`story` | `uv run csi-lab samples` |
| `data/my-recordings/` | 自分の ESP32 受信機で記録したもの | `uv run csi-lab capture --label <名前>` |

ファイルは CSV という形です。Python で開けるし、表計算ソフトでも開けます。
1 行が 1 パケットで、`time_s`（時刻）、`rssi_dbm`（強さ）、`label`（していたこと）、
そのあとに 56 本のサブキャリアの振幅（`sc-28` … `sc28`）がならびます。

**人を記録したデータは、人にわたさないでください。** Wi-Fi の記録を見ると、
だれがいつ家にいて、何をしていたかがわかってしまうことがあります。
見せるのはグラフや数字にして、記録した人から「いいよ」をもらってからにしましょう。
[安全のページ](../start_here/04_safety.ja.md) も読んでください。
