# 2 台の ESP32 に書きこむプログラム

| フォルダ | ボード | すること |
|---|---|---|
| [`csi_tx/`](csi_tx/csi_tx.ino) | **S**（送信機） | Wi-Fi チャンネル 11 で、1 秒に 100 回小さなパケットを送ります（ESP-NOW） |
| [`csi_rx/`](csi_rx/csi_rx.ino) | **R**（受信機） | S からのパケットの CSI を測って、1 行ずつ PC に送ります |

くわしい手順（おうちの人といっしょに）: [レッスン 3](../lessons/3-build/README.ja.md)

## ポイント

- Arduino IDE 2 →「ボードマネージャ」→「esp32 by Espressif Systems」→ ボードは **ESP32 Dev Module**
- ルーターもパスワードもいりません。2 台のチャンネル（`WIFI_CHANNEL`、ふつうは 11）をそろえます。
- R と PC の通信速度は **921600**。`uv run csi-lab capture ...` を動かす前に、
  シリアルモニタは閉じてください（ポートは 1 つのプログラムしか使えません）。
- R が出す 1 行（56 本のサブキャリアの振幅。-28〜-1、1〜28 の順）:

  ```text
  CSI,<時刻_us>,<RSSI_dBm>,<振幅 sc-28>,...,<振幅 sc28>
  ```

  `#` で始まる行はお知らせ（準備完了・状況・エラー）です。
- R は、このプロジェクトの目印がついたパケットだけを使います。近くのほかの Wi-Fi 機器は無視します。
- モジュールに **技適マーク** があるボードを使ってください。アンテナや送信の強さは変えないでください。
  [安全ガイド](../guides/safety.ja.md) も読んでください。

## 確認したこと

- Arduino-ESP32 コア 2.0.17（PlatformIO `espressif32@6.9.0`）でコンパイルできます。
- コア 3.x でもコンパイルできるように書いてありますが、**まだ確かめていません**。
  うまくいかないときは issue で知らせてください。
