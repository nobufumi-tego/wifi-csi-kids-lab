# 4-3. うまくいかないところ — その理由は？

[4-2](02_threshold.ja.md) の検出器は 87 % 当たりました。このページでは、残りの 13 % を見て、
なぜまちがえたのかを考えます。

> 💡 **このページのコードを動かすには**: ラボを起動して（`./start.sh` か `start.bat` を
> ダブルクリック、または `uv run lab.py`）、[`notebooks/01_motion_detector.ipynb`](notebooks/01_motion_detector.ipynb) を開きます。
> ターミナルがはじめての人 → [0-2. ターミナルと uv](../start_here/02_terminal_and_uv.ja.md)

## 1. 「still」がときどき動いているように見える

「じっと」座っている人も、ときどき姿勢を直します。本物の人もそうするので、シミュレーターには
わざとこの小さな姿勢の変化を入れてあります。4-2 のお話の記録では、「still」の 20 この窓のうち
1 こ（5 %）が「動いている」と判定されました。

これは検出器のまちがいでしょうか？ それとも本当に何かが動いたのでしょうか？ ラベルは「still」でも、
体は少し動いていました。**ラベルは人が書いたもので、かんたんすぎることがあります。**

## 2. 「wave」（手をふる）を見のがしやすい

手は小さいので、はね返る電波も小さくなります。手をふっているときの動きの数字（`seed=1` で中央値
0.0385）は、じっと座っているとき（0.0302）より少し大きいだけです。お話の記録では、「wave」の
窓のうち 40 % しか「動いている」と判定されませんでした。

## 3. 1 本のしきい値では、すべてに合わせられない

しきい値を下げると、手をふるのをたくさん見つけられますが、姿勢の変化もたくさん「動いた」と
言ってしまいます。上げると、手をふるのをもっと見のがします。ためしてみましょう。

```python
import numpy as np
from csi_lab import simulate, simulate_sequence
from csi_lab.features import motion_score, window_features, detect_motion

_, still_motion = motion_score(simulate("still", duration_s=30, seed=1))
story = simulate_sequence(
    [("empty", 20), ("walk", 20), ("still", 20), ("walk", 10), ("wave", 20), ("empty", 10)],
    seed=100,
)
w = window_features(story)
motion = w.features[:, w.names.index("motion")]
truth = np.isin(w.labels, ["walk", "wave"])

for margin in [1.0, 1.2, 1.5]:
    predicted = detect_motion(motion, threshold=still_motion.max() * margin)
    wave = predicted[w.labels == "wave"].mean()
    print(f"余裕 {margin}: 正解率={(predicted == truth).mean():.2f}  wave を見つけた割合={wave:.0%}")
```

結果（シミュレーター、seed は 4-2 と同じ）:

| 余裕 | 正解率 | 「wave」を見つけた割合 |
|---|---|---|
| 1.0 | 0.88 | 45 % |
| 1.2 | 0.87 | 40 % |
| 1.5 | 0.86 | 35 % |

この「あちらを立てればこちらが立たず」は、火災報知器や迷惑メールのフィルターなど、
世の中のほとんどの検出器にある悩みです。

## 4. 本物の部屋はもっとむずかしい

シミュレーターは、部屋をかんたんにまねしたものです。本物の部屋では、

- ほかの人、ペット、せんぷうき、カーテンが動く
- 自動の音量調整がもっとばらばらで、信号の雑音も多い
- ボードを少し動かすだけで、ぜんぶが変わる

だから、自分の記録の数字はちがってきます。たいてい「still」と「walk」の差はもっと小さくなります。
それは失敗ではありません。測ってみたからこそわかったことです。

> 🤖 **AI に聞いてみよう**
> - 「わたしの動き検出器は、人がいすの上で少し姿勢を変えただけで『動いた』と言ってしまいます。
>   直すアイデアを 3 つ出して、それぞれどんな新しいまちがいが起きそうかも教えてください」
> - 「火災報知器はなぜ完ぺきにならないの？ わたしの動き検出器とつなげて説明して」

## たしかめよう

1. 「wave」が「walk」より見つけにくいのはなぜですか？
2. しきい値を下げると、どうなりますか？
3. 自分の本物の記録が、シミュレーターとちがって見えそうなのはなぜですか？

<details><summary>こたえ</summary>

1. 手は小さいので、はね返る電波も小さく、ゆれがじっと座っているときより少し大きいだけだから
2. 小さな動き（手をふるなど）をたくさん見つけられるが、姿勢の変化も「動いている」と言うことが増える
3. 本物の部屋には動くものが多く、雑音も多く、かんたんなモデルよりずっと複雑だから
