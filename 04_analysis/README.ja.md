# 第 4 章: 動きを見つける — 動きの検出器を作ろう

CSI を 1 秒ごとの **「動きの数字」** に変えて、データから **しきい値** を決め、検出器がどれくらい
当たるかを確かめます。そして、**うまくいかない場面** とその理由を考えます。

## この章でできるようになること

- CSI を見る前に、パケットごとに **正規化** する理由を説明できる
- 1 秒の窓と標準偏差で、動きの数字を計算できる
- 「だれも動かない」記録からしきい値を決めて、正解率を測れる
- かんたんな検出器が見のがす場面と、その理由がわかる
- シミュレーターの中で、ゆっくりした規則正しいリズム（呼吸）を見つけ、その限界がわかる

**だれ向け:** 中学生〜（小学生は手伝ってもらいながら） ・ **時間:** 60〜90 分くらい

**必要なもの:** このラボの準備ができたパソコン。ハードウェアはいりません。シミュレーターを使います。
[第 3 章](../03_build/README.ja.md) でボードを作った人は、自分の記録でも試せます
（`from csi_lab import load_csv`）。
