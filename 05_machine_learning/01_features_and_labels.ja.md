# 5-1. 特徴量とラベル — 記録を表にする

機械学習には、きちんと整理された例が必要です。**問題** と、その **答え** です。
このページでは、CSI の記録をそういう表に変えます。

> ダブルクリック、または `uv run lab.py`）、[`notebooks/01_first_machine_learning.ipynb`](notebooks/01_first_machine_learning.ipynb) を開きます。

## ルールを書く から ルールを学ぶ へ

第 4 章では、「`motion` がしきい値より大きければ、だれかが動いている」というルールを 1 つ書きました。
答えが 2 つ（動いている／動いていない）なら、それでうまくいきました。今度は答えを **4 つ** にします。

| ラベル | そのとき起きていたこと |
|---|---|
| `empty` | 部屋にだれもいない |
| `still` | 人がじっと座っている |
| `walk` | 人がボードの間の線を横切って歩く |
| `wave` | 人が座って手をふる |

窓ごとに数が 5 つもあると、ルールを手で書くのは大変です。機械学習を使うと、コンピューターが
**たくさんの例を見て、ルールを見つけて** くれます。

## 窓 1 つ ＝ 表の 1 行

第 4 章と同じように、記録を 1 秒ずつの窓に切ります。窓 1 つが、表の **1 行** になります。

```python
from csi_lab import simulate_sequence
from csi_lab.features import window_features

steps = [("empty", 60), ("still", 60), ("walk", 60), ("wave", 60)]
w = window_features(simulate_sequence(steps, seed=1))

print(w.names)          # 列の名前（特徴量）
print(w.features[:3])   # 最初の 3 行
print(w.labels[:3])     # その 3 行の正解
print(w.features.shape) # （行の数, 列の数）
```

`seed=1` だと、表は 240 行（ラベルごとに 60 行）、5 列になります。最初の 3 行はこうです（四捨五入しています）。

| motion | motion_max | spread | rssi_std_db | change_rate | label |
|---|---|---|---|---|---|
| 0.0303 | 0.0345 | 0.2764 | 1.0563 | 0.0345 | empty |
| 0.0303 | 0.0358 | 0.2756 | 1.0017 | 0.0338 | empty |
| 0.0307 | 0.0347 | 0.2758 | 0.9563 | 0.0348 | empty |

- **特徴量**（とくちょうりょう、`w.features`）＝ 問題用紙: それぞれの窓の様子を表す数
- **ラベル**（`w.labels`）＝ 解答: 本当に起きていたこと

## 5 つの特徴量の意味

| 特徴量 | 意味 |
|---|---|
| `motion` | 振幅のゆれの大きさを、全部のサブキャリアで平均したもの（第 4 章の「動きの数字」） |
| `motion_max` | いちばん大きくゆれたサブキャリアのゆれ |
| `spread` | サブキャリアどうしが、どれくらいちがうか（部屋の「指紋」のようなもの） |
| `rssi_std_db` | 信号の強さ（RSSI）のゆれ。単位は dB |
| `change_rate` | パケットからパケットへ、振幅がどれくらい速く変わるか |

たとえば、サブキャリア $k$ のゆれ（時間方向の標準偏差）を $\sigma_k$（シグマ）と書くと、
`motion` は 56 本のサブキャリアの平均です。

$$\text{motion} = \frac{1}{56} \sum_{k} \sigma_k$$

## 1 行は「数の並び」

`[0.0303, 0.0345, 0.2764, 1.0563, 0.0345]` のような 1 行は、**5 つの数の並び** です。
数学ではこれを **ベクトル** とよびます。5 つの方向がある空間の「点」だと考えることもできます。
にている窓は、近くにある点になります。機械学習は、これを使って見分けます。

> 🤖 **AI に聞いてみよう**
> - 「機械学習の『特徴量』って何？ 通知表をたとえに使って説明して」
> - 「わたしの表の 1 行は [0.03, 0.035, 0.28, 1.06, 0.035] です。答えを言う前に、それぞれの数が何を表すと思うか、質問してください」

## たしかめよう

1. この表の 1 行は、何を表していますか？
2. 特徴量とラベルのちがいは何ですか？
3. ラベルが 4 つあると、ルールを手で書くのがむずかしいのはなぜですか？

<details><summary>こたえ</summary>

1. 記録の中の、1 秒の窓 1 つです。
2. 特徴量は窓の様子を表す数（問題）、ラベルは本当に起きていたこと（答え）です。
3. 窓ごとに数が 5 つあり、答えも 4 つあるので、考える組み合わせがとても多いからです。例からルールを見つけるのはコンピューターに任せたほうが楽です。

</details>
