# 第 5 章: はじめての機械学習

[第 4 章](../04_analysis/README.ja.md) では、**あなたが** 数を 1 つとしきい値を 1 つ選びました。
この章では、コンピューターが **例を見て、自分でルールを見つけます**。
機械学習でいちばん大切な習慣も身につけましょう。公平にテストすること、
そしてうまくいかなかったときも **正直に報告すること** です。

## この章のゴール

- **自分で書くルール** から、**コンピューターが学ぶルール** へ進む
- **練習に使ったデータでテストしてはいけない** 理由がわかる
- **決定木**（けっていぎ）を学習させて、見つけたルールを読める
- **混同行列**（こんどうぎょうれつ）の読み方と、**過学習**（かがくしゅう）がわかる
- むずかしいテスト「**一度も見たことのない部屋**」をためす

**対象:** 中学生〜。第 4 章を終えた人。
**時間:** ぜんぶで 90 分くらい（2 日に分けても OK）
**必要なもの:** このラボを入れたパソコン。`uv sync`（または起動スクリプト）で、scikit-learn も
ふくめて全部入ります。ESP32 ボードはいりません。
